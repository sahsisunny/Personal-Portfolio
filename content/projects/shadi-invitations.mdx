## Deep Dive: Mobile-First Indian Wedding Invitation Platform

**Shadi Invitation Website** is a mobile-first digital invitation platform built with Next.js, TypeScript, and Framer Motion. Built to replace expensive, static PDF invitations, it provides interactive, personalized ceremony cards featuring animated temple door reveals, traditional auspicious motifs, map navigation, and one-tap guest RSVP actions.

### 1. Spring-Physics Opening Gate Reveal Animation

Indian wedding invitations traditionally start with an auspicious opening of ceremonial palace doors. We implemented a 60 FPS gesture-friendly gate reveal using Framer Motion spring physics:

```typescript
// components/invitation/opening-gate.tsx
"use client";

import { motion, AnimatePresence } from "framer-motion";
import { useState } from "react";

interface OpeningGateProps {
  onOpen: () => void;
  title: string;
}

export function OpeningGate({ onOpen, title }: OpeningGateProps) {
  const [isOpen, setIsOpen] = useState(false);

  const handleOpen = () => {
    setIsOpen(true);
    setTimeout(onOpen, 900);
  };

  return (
    <AnimatePresence>
      {!isOpen && (
        <motion.div
          className="fixed inset-0 z-50 flex items-center justify-center overflow-hidden bg-amber-950"
          exit={{ opacity: 0, transition: { duration: 0.6, delay: 0.4 } }}
        >
          {/* Left Ceremonial Door */}
          <motion.div
            className="w-1/2 h-full bg-red-900 border-r-2 border-amber-400/60 shadow-2xl flex items-center justify-end pr-4"
            animate={{ x: isOpen ? "-100%" : 0 }}
            transition={{ type: "spring", stiffness: 80, damping: 18 }}
          />

          {/* Right Ceremonial Door */}
          <motion.div
            className="w-1/2 h-full bg-red-900 border-l-2 border-amber-400/60 shadow-2xl flex items-center justify-start pl-4"
            animate={{ x: isOpen ? "100%" : 0 }}
            transition={{ type: "spring", stiffness: 80, damping: 18 }}
          />

          {/* Center Royal Seal Button */}
          <motion.button
            onClick={handleOpen}
            whileHover={{ scale: 1.05 }}
            whileTap={{ scale: 0.95 }}
            className="absolute z-10 px-6 py-3 rounded-full bg-amber-400 text-amber-950 font-bold shadow-lg"
          >
            {title || "निमंत्रण पत्र खोलें"}
          </motion.button>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
```

### 2. Plug-and-Play Template Architecture

New templates can be added by declaring a new template definition without altering core layout routes. English numerals are automatically formatted to avoid font mismatches across older mobile browsers while preserving classical Devanagari headings.
