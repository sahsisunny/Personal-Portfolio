## Deep Dive: Modern Headless E-Commerce Storefront

**SweetCart** is an e-commerce storefront engineered with React, Next.js, Tailwind CSS, and Framer Motion. Built to demonstrate headless commerce integration, it combines dynamic catalog querying via Commerce.js REST endpoints, persistent local cart state, and performant micro-interactions designed for conversion.

### 1. Commerce.js Headless API Integration

Product catalogs and dynamic SKU pricing are synchronized directly through Commerce.js REST SDK:

```typescript
// lib/commerce.ts
import Commerce from "@chec/commerce.js";

export const commerce = new Commerce(
  process.env.NEXT_PUBLIC_CHEC_PUBLIC_KEY || "demo-key",
  true
);

export async function fetchProductsByCategory(categorySlug?: string) {
  try {
    const { data: products } = await commerce.products.list({
      category_slug: categorySlug ? [categorySlug] : undefined,
    });
    return products;
  } catch (error) {
    console.error("Failed to load catalog products:", error);
    return [];
  }
}
```
