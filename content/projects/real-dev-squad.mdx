## Deep Dive: Open Source Engineering with Real Dev Squad

**Real Dev Squad (RDS)** is a community-driven open-source developer ecosystem that empowers software engineers to collaborate on production-grade web applications, developer triage portals, and real-time community tools.

Contributing to Real Dev Squad involved working across diverse frontend technology stacks—including **Vue.js**, **Vuetify**, **React**, **Next.js**, and **Ember.js**—under strict distributed peer review standards, test automation, and accessibility requirements.

### 2. Role-Based Accordion Lock & Security Guardrails

Implemented access control restrictions on sensitive administrative configuration accordions. When a user lacking required permissions views the accordion, the interactive toggle is disabled and displays a clean visual indicator informing them of insufficient permissions, preventing unauthenticated state mutations:

```javascript
// composables/useAccordionGuard.js
export function useAccordionGuard(currentUser, requiredRole = "admin") {
  const isAuthorized = computed(() => {
    if (!currentUser.value) return false;
    return currentUser.value.roles?.includes(requiredRole);
  });

  const handleAccordionToggle = (accordionId) => {
    if (!isAuthorized.value) {
      notify({
        type: "warning",
        message: "You must have contributor or administrator permissions to modify this section.",
      });
      return false;
    }
    return true;
  };

  return { isAuthorized, handleAccordionToggle };
}
```

### 3. Member Status Triage & Pull Request Activity Tracker

To improve community engagement visibility and member tracking, contributed features across community dashboards:

- **Status Filters:** Added dynamic filtering to list members based on active status, onboarding state, or inactive standing, streamlining triage for community leaders.
- **Profile PR Tracker:** Built an automated widget that interfaces with GitHub API metadata to display a contributor's merged and open pull requests directly on their public community profile page.
- **Collaborative Code Reviews:** Actively reviewed community pull requests, adhered to conventional commits, and ensured test coverage across multiple repositories.
